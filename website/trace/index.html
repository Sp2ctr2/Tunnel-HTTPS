TRACE는 새로운 은행 앱인가요?
아닙니다. TRACE는 기존 은행 앱과 보안 체계에 거래 전의 위험 맥락을 더하는 보안 계층을 지향합니다. 현재는 Android 참조 은행 앱과 SDK, 선택적으로 실행하는 은행 통합 시뮬레이터로 구성된 프로토타입입니다.
제 통화와 문자를 계속 듣고 읽나요?
현재 참조 구현은 통화를 자동 청취하거나 문자함을 자동 수집하지 않습니다. 사용자가 직접 공유·입력한 텍스트, 또는 버튼을 눌러 시작한 지원 기기의 온디바이스 음성 입력을 분석합니다. 이 웹사이트는 준비된 가상 데이터만 사용하며 마이크나 문자 권한을 요청하지 않습니다.
AI가 제 돈을 마음대로 막을 수 있나요?
AI는 위험 신호를 구조화하는 역할입니다. 실제 거래의 허용, 추가 확인, 보류 등은 호스트 은행의 정책과 권한 경계에서 결정하도록 설계되어 있습니다. 웹 체험의 ALLOW·HOLD·VERIFY는 미리 정의한 시나리오를 보여 주는 UI 시연이며 실제 금융거래를 실행하거나 차단하지 않습니다.
지금 바로 실제 계좌에 사용할 수 있나요?
아직 아닙니다. 2026년 9월 12일 작업 요약 기준으로 TRACE는 보안 경계를 검증하는 참조 구현·대회용 프로토타입입니다. 실제 금융기관 연동, 운영 승인, 실제 사용자 환경과 모델 성능 검증은 별도 단계입니다. 상용 도입이나 탐지 정확도를 보증하는 수치는 제시하지 않습니다.
