# 스토어 등록정보 초안 — 한국어

앱 이름 후보: Tunnel HTTPS

짧은 설명: Android VpnService를 사용하는 로컬 DNS 및 HTTPS 연결 도구

상세 설명: Tunnel HTTPS는 기기에 로컬 VPN 인터페이스를 만들어 DNS over HTTPS 조회, DNS 기반 광고 도메인 차단, 앱 우회 선택, 로컬 TCP/UDP 연결 처리를 제공합니다. 모든 트래픽을 일반적인 원격 VPN 서버로 보내지 않으며 HTTPS 내용을 복호화하지 않습니다. 모드에 따라 더 많은 트래픽을 캡처하며 IPv6와 UDP/443에는 명시해야 할 제한이 있습니다. DNS 질의는 지원되는 외부 DoH 리졸버에서 처리될 수 있습니다.

주요 기능: 로컬 VpnService, DoH 선택, DNS 도메인 차단, 앱/브라우저 우회 규칙, 규칙 기반 Turbo 조정, 연결 해제 동작이 있는 포그라운드 알림.
