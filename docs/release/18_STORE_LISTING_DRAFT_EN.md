# Store listing draft — English

Title candidate: Tunnel HTTPS

Short description: Local DNS and HTTPS connection utility using Android VpnService.

Full description: Tunnel HTTPS creates a local VPN interface on your device to apply DNS-over-HTTPS resolution, DNS-based ad-domain blocking, application bypass choices, and local TCP/UDP connection handling. It does not route all traffic to a conventional remote VPN server and does not decrypt HTTPS content. Some modes capture more traffic and have documented IPv6 and UDP/443 limitations. DNS queries may be processed by supported third-party DoH resolvers.

Core features: local VpnService operation; DoH selection; DNS-domain blocking; app/browser bypass rules; deterministic Turbo tuning; foreground notification with disconnect action.
