# Play Console checklist

- [ ] Organization developer account confirmed for approved `VpnService` use.
- [ ] Adult account owner and identity verified.
- [ ] Organization details and D-U-N-S verified where required.
- [ ] Developer/public contact details complete.
- [ ] Existing `com.tunnelvpn.app` registration ownership confirmed.
- [ ] Play App Signing and upload key prepared/backed up.
- [ ] Signed AAB uploaded to internal testing.
- [ ] Closed-test requirement determined from account type/date; if applicable, 12 opted-in testers for 14 continuous days completed.
- [ ] Production access application completed if applicable.
- [ ] Category, tags, country availability, and pricing selected.
- [ ] Hosted privacy-policy URL supplied in app and Console.
- [ ] Ads, app access, target audience, and content rating completed truthfully.
- [ ] Data Safety answers reviewed against `04_DATA_INVENTORY.md`.
- [ ] VpnService declaration and video submitted.
- [ ] Foreground-service declaration and video submitted.
- [ ] Prominent disclosure and consent implemented/tested.
- [ ] Store listing, icon, feature graphic, screenshots, and release notes finalized.
- [ ] Pre-launch report/device catalog reviewed.
- [ ] Manual network/OEM/IPv6 matrix completed.
- [ ] Staged rollout and post-release vitals ownership assigned.

All identity, contract, payment, declaration submission, tester, video, and publication actions are manual.
