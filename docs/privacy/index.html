02 / INTEGRITY

Verify before you install.

Compare the APK’s SHA-256 with the checksum published alongside that exact release. For update identity, also compare the Android signing certificate.

Choose a file to calculate its SHA-256. Maximum 128 MiB.

A matching checksum establishes byte-for-byte equality with the published value. It is not an independent security audit or proof that the application is safe.

03 / FIRST CONNECTION

A deliberate first connection.

  1. Install the official APK.

    Android may require permission for the particular app you use to open the download. Do not disable device-wide security protections.

  2. Read the disclosure.

    Review which network metadata is processed and where DNS queries can go.

  3. Grant Android VPN consent.

    The system VPN prompt authorizes the local VpnService interface. It does not mean that a remote VPN exit server is being used.

  4. Connect and check normal browsing.

    Evaluate on a network you control. Disconnect from the application if your connectivity is affected.

Build and test locally +

./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest :app:lintDebug

The development APK is written to app/build/outputs/apk/debug/app-debug.apk.

Install a local development APK +

With an authorized Android device or emulator connected:

adb install -r app/build/outputs/apk/debug/app-debug.apk

A debug build is not the official signed release. Keep signing keys and local configuration out of Git history.

Privacy & boundaries ↗
Will this change my public IP or country? +

No. There is no developer-operated remote exit gateway. Destination services and chosen resolvers still receive requests over the underlying network.

Can I use another Android VPN at the same time? +

Android normally supports one active VpnService-based VPN per user or profile. Another VPN can replace or conflict with this local engine.

Does the website run the networking engine? +

No. The packet explorer is an explanation, not a browser port of the Android networking engine. It generates no network test traffic.

Where should I report a problem? +

Use the repository’s issue process for ordinary bugs. For an exploitable vulnerability, follow SECURITY.md. Do not publish private browsing data, credentials or sensitive packet captures.

Privacy & boundaries / 04

Clear boundaries.
Better trust.

Local processing is a specific architectural choice. It is not a promise of anonymity, universal bypass or invisibility.

01 / THE APPLICATION

What “local” means.

The Android engine processes selected network packets and metadata on the device. That may include destination addresses, ports, DNS names and visible TLS ClientHello metadata.

The developer does not operate a remote full-traffic VPN gateway. Application requests still reach destination services, and configured DNS resolvers receive the queries sent to them.

Inspect the documented data flow ↗
02 / THIS WEBSITE

A site, not a collector.

This interface has no analytics SDK, advertising script or account form. Theme and motion preferences are stored locally in the browser when storage is available.

The APK checker reads the selected file locally to calculate its hash. It does not upload the file. GitHub, which hosts the site and releases, may process ordinary request metadata under its own policies.

03 / EXPECTATIONS

What is not claimed.

No public-IP hiding or country switching. No HTTPS payload decryption. No complete replacement for Linux TCP or a full QUIC implementation. No guarantee that every network or application will behave identically.

Aegis remains an experimental shadow policy. The website’s animations and explorer are illustrations, not live diagnostic evidence.

04 / RESPONSIBLE USE

Keep the testing yours.

Use controlled devices, synthetic data and networks you are authorized to test. Do not collect other people’s traffic or treat the application as an authorization bypass.

Public documentation cannot prevent every possible misuse of open-source code. Safety depends on implementation boundaries, careful distribution and responsible operation as well as clear explanations.
